Project Description
  This is a Lost and Found Management System that allows users to report lost or found items through a simple web interface. Users can add items, search for them, and claim items once verified.
  The system uses a frontend interface connected to a backend server and database to store and manage item details securely.
  
The Problem Statement

There is no proper digital system to manage lost and found items, making it difficult for people to recover their belongings.
A simple online platform is needed to report, search, and claim lost items efficiently.

The Solution

Our solution provides a centralized web platform where users can easily report lost or found items, search for them, and claim them through a structured verification process. 
This reduces confusion, improves tracking, and increases the chances of returning items to their rightful owners quickly and efficiently.

Features
1.Item Reporting System
Users can easily report lost or found items by filling out a simple form with details like item name, description, location, and date.
This ensures all items are recorded in a structured way.

2.Search & View Items
Users can search and browse through all reported items. 
This makes it easy to quickly check whether a lost item has already been found and listed in the system.

3.Claim & Verification Process
Users can claim an item by submitting proof of ownership.
Once verified, the item is marked as claimed and removed from the active list, ensuring proper tracking and preventing duplicate claims.

Software Installation
Install the following software:
Node.js – To run the backend server
MongoDB – For database storage
VS Code – Code editor
Git – Version control

 Project Setup Commands
Step 1: Create Project Folder
Bash
mkdir lost-found
cd lost-found
Step 2: Initialize Node Project
Bash
npm init -y
Step 3: Install Required Packages
Bash
npm install express mongoose cors

 Running MongoDB
Start MongoDB in terminal:
Bash
mongod
Open another terminal to access MongoDB shell:
Bash
mongosh

Running the Backend Server
Start the server:
Bash
node server.js
If using nodemon:
Bash
npx nodemon server.js
Server will run on:


http://localhost:5000
Running the Frontend
Simply open:


index.html
OR use Live Server in VS Code.
